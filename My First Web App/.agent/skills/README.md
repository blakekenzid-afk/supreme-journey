# 🛠️ Teacherstack Skills

Welcome to your skills library! These files are instructions that I (Antigravity) use to help you build your app faster without you having to write a single line of code.

## 🚀 How to use them
Simply tell me what you want to do, and I'll look for a matching skill. For example:
- *"Add a new student named Leo"* (Triggers `add_student.md`)
- *"Add a noise meter to the whiteboard"* (Triggers `add_whiteboard_tool.md`)

## ✍️ Creating your own
If you find yourself asking me to do the same thing over and over, we should create a new skill for it!
1. Create a `.md` file in this folder.
2. Define a **Trigger** (what you will say to start it).
3. List the **Steps** (what files to open and what code to add).
